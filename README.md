# 🏨 The Grand – Resort & Spa Hotel Website

A responsive hotel and resort website designed and developed using **HTML, CSS, and JavaScript**. The website provides an elegant and modern interface for showcasing hotel rooms, offers, penthouse accommodations, press features, and contact information.

## 🌐 Live Demo

🔗 **Live Website:** https://bansibhatti.github.io/Hotel_Website/

## 📌 About The Project

**The Grand – Resort & Spa Hotel** is a multi-page hotel website created with a clean, luxurious, and responsive design.

The website includes different sections for exploring the hotel, viewing accommodations, checking promotional offers, learning about the Grand Penthouse, reading press highlights, and contacting the hotel.

## ✨ Features

* 🏠 Home page with hero sections
* ℹ️ About the hotel
* 🛏️ Accommodation / Rooms section
* 🏢 Grand Penthouse page
* 🎁 Promotions and special offers
* 📰 Press and testimonials section
* 📞 Contact and reservation information
* 📱 Responsive navigation menu
* ☰ Mobile-friendly hamburger menu
* ⭐ Hotel awards section
* 🖼️ Image-based room and gallery sections

## 📄 Pages

### Home

Introduces **The Grand Resort & Spa Hotel** with a hero section, hotel highlights, and awards.

### About

Provides information about the hotel and presents the hotel's luxurious atmosphere.

### Accommodations

Displays available rooms including:

* Deluxe Room
* Deluxe Sea View
* Premier City View
* The Grand Family Suite
* Executive Suite
* The Grand Penthouse

### The Grand Penthouse

Showcases the penthouse with:

* Main room image
* Dining area
* Bathroom
* Floor plan
* Room descriptions

### Promos

Displays hotel offers such as:

* Early Bird Discount
* Grand Members Club
* Book 3 Nights, Get 1 Night Free
* Milestone Discount
* Restaurant Promo
* Business Event Package

### Press

Contains press highlights and testimonials from travel publications.

### Contact

Provides reservation office details, office hours, and social media information.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**

The pages use a shared `style.css` file and external Google Fonts / Font Awesome resources.

## 📱 Responsive Design

The website includes a responsive navigation menu with a hamburger button for smaller screen sizes. JavaScript is used to open and close the mobile navigation menu.
